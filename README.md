# 🎵 Music Streaming Platform - Backend

## 📋 О проекте

Backend-часть музыкальной стриминговой платформы, разработанной на Spring Boot. Платформа позволяет пользователям загружать, прослушивать и оценивать музыкальные треки.

## 🚀 Основные возможности

### 🔐 Аутентификация и безопасность
- **Регистрация** с подтверждением email
- **Вход в систему** через Spring Security
- **Восстановление пароля** по email
- **Ролевая модель** (USER/ADMIN)
- **Защита API** от неавторизованного доступа

### 🎶 Музыкальный функционал
- **Загрузка треков** с метаданными (исполнитель, жанр, обложка)
- **Поиск треков** по названию, исполнителю, жанру
- **Лайки/дизлайки** треков
- **Скачивание треков** с безопасной проверкой прав доступа

### 👥 Управление пользователями
- **Поиск пользователей** по email
- **Изменение ролей** (административный функционал)
- **Статистика пользователей** (подтвержденные/неподтвержденные)
- **Удаление пользователей** с проверкой прав

### 📧 Email уведомления
- **Автоматическая отправка** писем подтверждения
- **Шаблоны Thymeleaf** для красивых HTML-писем
- **Rate limiting** для защиты от спама
- **Поддержка популярных почтовых сервисов**

## 🏗️ Архитектура

### Стек технологий
- **Java 17+** - основной язык
- **Spring Boot** - фреймворк
- **Spring Security** - аутентификация и авторизация
- **Spring Data JPA** - работа с БД
- **PostgreSQL** - база данных
- **Lombok** - сокращение boilerplate-кода
- **Thymeleaf** - шаблоны email
- **JavaMail** - отправка email

## 📊 База данных
```sql
userdata    - Пользователи (роли, токены, верификация)
tracks      - Музыкальные треки (метаданные, файлы)
likes       - Лайки (связь пользователь↔трек)
```

## Структура проекта
```
src/main/java/vsu/cs/oop2/
├── Controllers/ # REST и Templates контроллеры
├── Services/ # Бизнес-логика
├── Repository/ # Репозитории для работы с БД
├── Entity/ # JPA сущности
├── DTO/ # Data Transfer Objects
│ ├── Authorization/ # DTO для аутентификации
│ ├── Search/ # DTO для поиска
│ └── ApiResponse.java # Стандартный ответ API
├── Exceptions/ # Кастомные исключения
│ ├── EmailException/ # Исключения для email
│ └── TokenExceptions/ # Исключения для токенов
├── Security/ # Конфигурация безопасности
└── Utils.java # Вспомогательные методы
```

## 🛡️ Безопасность
- **Хеширование паролей с использованием BCrypt**
- **Токены с ограниченным сроком действия**
- **Защита от CSRF**
- **Валидация входных данных на всех уровнях**
- **Rate limiting для защиты от брутфорса**

## Планы по развитию
- Миграция на **Vue.js** для современного фронтенда и соответствующая **пагинация**
- Интеграция **RabbitMQ/Kafka** для асинхронной обработки
- Микросервисная архитектура для масштабирования
- Реализация рекомендательной системы на основе лайков
